# Dashboard Builder (Home Assistant App)

Touchscreen-friendly Home Assistant dashboard with free-form widgets, rooms, energy, screensaver, and more.

Install this repository as an **app repository** in Home Assistant (see [DOCS.md](DOCS.md)).

## Ingress

The app is available via **Open Web UI** / the sidebar (Home Assistant Ingress). Authentication is handled by Home Assistant.

## Direct port

Port `3000` is optional. If enabled, open:

`http://homeassistant.local:3000/__ha_ingress__/`
